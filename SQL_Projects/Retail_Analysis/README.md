### 📊 **Retail Sales Analysis using SQL**

---

## 📌 Project Overview

* This project focuses on analyzing retail sales transaction data using SQL to uncover meaningful business insights. The analysis covers customer demographics, sales performance, product categories, and time-based trends to support data-driven decision-making.

* The objective is to demonstrate practical SQL skills used in real-world retail analytics scenarios, including data cleaning, exploratory analysis, and business-focused querying.

---

## 🧾 Dataset Description

The dataset represents retail transaction-level sales data with the following attributes:

* **Transaction ID** – Unique identifier for each transaction

* **Sale Date & Time** – Date and time of purchase

* **Customer ID** – Unique customer identifier

* **Gender & Age** – Customer demographics

* **Category** – Product category

* **Quantity** – Units sold per transaction

* **Price per Unit** – Selling price of each unit

* **COGS** – Cost of goods sold

* **Total Sale** – Total transaction value

## 🔍 Analysis Performed

The project includes the following analytical steps:

**1. Data Preparation**

* Database and table creation

* Schema design with appropriate data types

* Identification of missing (NULL) values

* Data quality validation

**2. Exploratory Data Analysis (EDA)**

* Sales distribution across product categories

* Customer demographic analysis (age & gender)

* Transaction trends by date and time

* Revenue and quantity-based performance metrics

**3. Business-Oriented Queries**

* Identifying high-performing product categories

* Analyzing customer purchase behavior

* Evaluating sales trends over time

* Revenue contribution analysis

---

## 📈 Key Insights

* Certain product categories contribute disproportionately to total revenue.

* Sales activity shows variation based on time and customer demographics.

* Customer age and gender influence purchasing patterns.

* High-value transactions are driven more by price than quantity in some categories.

**(Insights can be extended further using BI or visualization tools.)**
