# Trader Behavior Analysis Based on Market Sentiment

### Objective
The goal of this project is to analyze how Bitcoin market sentiment
(Fear, Greed, Extreme Fear, Extreme Greed) impacts trader behavior
and profitability using historical trade data.

---

## Datasets Used

### 1. Bitcoin Market Sentiment Dataset
- Contains daily market sentiment classifications such as Fear and Greed.
- Used to understand overall market psychology.

### 2. Historical Trader Data
- Contains individual trade-level information such as execution price,
  trade size, side (buy/sell), and closed profit/loss (PnL).
- Analysis focuses on Bitcoin trades only.

---

# Trader Behavior Insights Based on Market Sentiment

## Overview
This project explores the relationship between Bitcoin market sentiment
(Fear and Greed Index) and trader performance using historical trading data.

---

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib

---

## Key Insights
- Median trade profitability is zero across all sentiment regimes.
- Greed periods exhibit higher trade activity and higher PnL volatility.
- Profitability is driven by a subset of high-impact trades.
